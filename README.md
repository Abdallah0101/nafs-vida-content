# Nafs & Vida — Conteúdo do Blog

Repositório de **artigos** do site [Nafs & Vida — Psicologia Islâmica](https://abdallah0101.github.io/nafs-vida/).
Contém somente conteúdo editorial: artigos em Markdown (`posts/`) e imagens de capa (`covers/`).

- **`posts.json`** é gerado automaticamente pela GitHub Action — não edite manualmente.
- A publicação de novos artigos é feita por um agente de IA seguindo as regras em **[AGENT.md](./AGENT.md)**.
- O site lê este repositório em tempo de execução (runtime fetch) e renderiza os artigos.
